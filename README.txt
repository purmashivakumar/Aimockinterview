AI MOCK INTERVIEW PRO
======================

FEATURES
--------
1. Login / Sign Up
2. 50 technical subjects
3. Java, C, C++, DSA included
4. Resume upload field + resume text extraction for TXT
5. Resume text/paste -> resume-based interview questions
6. Face-to-face interface with AI avatar
7. Camera + microphone permission
8. Speaking interview using browser Speech Recognition
9. AI interviewer reads questions using Speech Synthesis
10. Question score + final performance report
11. Mobile responsive

50 SUBJECTS
-----------
Java, C, C++, Data Structures & Algorithms, Python, JavaScript, HTML, CSS,
SQL, DBMS, Operating Systems, Computer Networks, Computer Architecture,
Software Engineering, OOP, Machine Learning, Artificial Intelligence,
Deep Learning, Data Science, Cloud Computing, Cyber Security, Git & GitHub,
React.js, Node.js, Express.js, Django, Flask, Spring Boot, MongoDB, MySQL,
PostgreSQL, REST API, System Design, Linux, DevOps, Docker, Kubernetes,
Power BI, Excel, Statistics, Discrete Mathematics, Compiler Design,
Theory of Computation, Web Development, Mobile App Development,
Natural Language Processing, Computer Vision, Generative AI,
Prompt Engineering, Agile & Scrum, Testing & QA.

RUN
---
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open index.html in Chrome.
4. Sign Up.
5. Go to Interview.
6. Upload a TXT resume OR paste resume text.
7. Select Java/C/C++/DSA/etc.
8. Click Prepare AI Interview.
9. Allow camera and microphone.
10. Click Speak Answer and answer aloud.

IMPORTANT
---------
This is a front-end hackathon-ready prototype. It does not call an external AI API.
The "AI" behavior is implemented with resume keyword-based question generation,
browser speech recognition and speech synthesis. This makes it easy to run
without API keys or a backend.

For a production version:
- Use a real authentication backend.
- Store resumes securely.
- Extract PDF/DOCX server-side.
- Connect an LLM API for deeper resume-based question generation and scoring.
- Add database, interview history and downloadable PDF report.
